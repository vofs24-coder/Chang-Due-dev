# Change Due

A simple, offline, ad-light change calculator for Android, built with Kotlin and Jetpack Compose.

## Features

- Automatic change calculation (received - total)
- "Still due" indicator when payment is insufficient
- Custom numeric keypad with blink cursor
- Auto-formatted thousands separator per region
- Everyday currency symbols (MT, $, €, ¥, R$, etc.)
- Single-line auto-fit result (shrinks text instead of wrapping)
- 10 languages: English, Portuguese, Spanish, French, Swahili, Arabic, Hindi, Japanese, Korean, Chinese
- Lightweight banner ad only
- 100% offline — no login, no backend, no tracking

## Build

This project is built automatically via GitHub Actions. See `.github/workflows/build.yml`.
